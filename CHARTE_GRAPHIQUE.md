# 🌐 Charte Graphique & Architecture — Site Vitrine & Portail Web

Ce document est le guide de référence pour le collaborateur en charge du **Site Vitrine Officiel et du Portail Web Public**.

---

## 🎯 1. Objectifs du Site Vitrine

* Présenter la coopérative, son agrément, ses valeurs et ses engagements.
* Mettre à disposition un **simulateur de crédit et d'épargne interactif** en temps réel.
* Permettre aux nouveaux adhérents de **remplir leur pré-dossier d'adhésion en ligne**.
* Servir de pont d'accès sécurisé vers l'**Espace Logiciel Gestionnaire** et le **Portail Sociétaire**.

---

## 🎨 2. Palette de Couleurs du Site

* **Arrière-plan :** Nuit Sombre (`#020617` / `bg-slate-950`) et Ardoise Carte (`#0f172a` / `bg-slate-900`)
* **Accents :** Vert Émeraude (`#10b981` / `text-emerald-400`), Sarcelle Électrique (`#2dd4bf` / `text-teal-300`)
* **Bordures :** Liserés fins `border-slate-800`

---

## 🚀 3. Commandes pour Travailler sur le Site

```bash
# Installation
npm install

# Démarrer le serveur de développement
npm run dev

# Compiler pour déploiement web (Vercel, Netlify, Cloud Run, Nginx)
npm run build
```
